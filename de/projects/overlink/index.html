Das Problem

KI-Chats können erklären, wie man etwas repariert, aber sie kommen nicht an deinen Computer. Coding-Agenten schon, aber sie stoßen schnell an ihre Nutzungsgrenzen und arbeiten immer nur auf einem Rechner.

Was ich gebaut habe

  • Die KI-Chats, die du schon nutzt, arbeiten auf deinen eigenen Windows-PCs: Dateien, Terminal und Browser.
  • Viele Computer hängen an einer Verbindung. Schick Dateien zwischen ihnen hin und her und verschieb eine Aufgabe auf einen anderen PC.
  • Jede Aktion wird in einfachen Worten festgehalten, und riskante Schritte warten auf dein OK.
  • Live-Ansicht pro PC: Zustand, letzte Aktionen und was gerade läuft.

So funktioniert es

Auf jedem PC läuft eine Windows-App (C#, WebView2). Ein Node.js-Dienst stellt ihre Werkzeuge über MCP bereit, und der KI-Chat verbindet sich mit dieser Verbindung. Eine Rechte-Schicht prüft jede Anfrage, bevor sie läuft, und ein Aktivitätsprotokoll speichert, was passiert ist.

Stand und Nachweis

  • Täglich im Einsatz auf meinen eigenen PCs.
  • Über 900 automatische Tests (Node.js und Python).
  • Produktvideos oben, öffentliche Übersicht auf GitHub.
