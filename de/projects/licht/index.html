Licht

Licht ist meine eigene Desktop-App, um mit mehreren KIs gleichzeitig zu arbeiten. Chats mit ChatGPT, Codex und Claude Code, Notizen und Werkzeuge liegen als Karten auf einer endlosen Fläche, statt in Browser-Tabs zu verschwinden.

Ich habe sie gebaut, weil ich meist fünf oder sechs KI-Chats am selben Projekt laufen habe und ständig den Überblick verlor, welcher was macht. Auf einer Fläche sehe ich alle, kann sie verschieben und nach Aufgabe gruppieren.

Eigenes Werkzeug · in Entwicklung

Warum ich es gebaut habe

An einem normalen Tag arbeite ich gleichzeitig mit ChatGPT, Codex und Claude Code, oft am selben Projekt. In Tabs und einzelnen Fenstern verlor ich ständig den Überblick, welcher Chat was macht und wo eine gute Antwort stand.

Ich wollte eine Arbeitsfläche, auf der ich alle auf einmal sehe, so wie man Papiere auf einem Schreibtisch ausbreitet.

Was es kann

Licht ist eine endlose Fläche. Jeder Chat, jede Notiz und jedes Werkzeug ist eine Karte, die du verschieben, in der Größe ändern und gruppieren kannst. Du kannst schieben und zoomen, mit einer Mini-Karte zwischen Bereichen springen und das Layout wechseln, wenn du dich auf einen Chat konzentrieren willst.

Codex und Claude Code laufen als echte Agenten in ihren Karten, du siehst ihnen also Schritt für Schritt bei der Arbeit zu. ChatGPT-Chats nutzen dein eigenes angemeldetes Konto, und zwei verbundene Karten lesen die Antworten der anderen, bevor sie antworten.

Dazu kommen die Funktionen, die ich am meisten nutze: ein Wettlauf zwischen Claude Code und Codex bei derselben Aufgabe, eine Übernahme, wenn einem das Kontingent ausgeht, eine Warteschlange mit Aufgaben, die die KI allein abarbeitet, ein Einbruch-Modus, in dem Agenten meinen eigenen Code angreifen und reparieren, was sie finden, und eine Heute-Karte, die zeigt, wohin meine Stunden und Tokens gegangen sind. Zu jeder gibt es unten ein kurzes Video.

Wie es gebaut ist

Licht ist eine Electron-App in reinem JavaScript. Codex und Claude Code laufen über ihre eigenen Kommandozeilen-Werkzeuge, ChatGPT über seine Website innerhalb der App.

Sie hat ihren eigenen Look: ein dunkles, gläsernes Design rund um das Chrom-Stern-Logo.

Wo es steht

Die Fläche selbst funktioniert gut. Die Verbindung zu den einzelnen KIs baue ich gerade neu, damit Chats zuverlässig und im Takt bleiben, statt kaputtzugehen, wenn sich eine Website ändert.

Im Moment ist es ein Werkzeug für meine eigene Arbeit, noch nichts, was andere installieren können. Die Anleitung oben zeigt den heutigen Stand.

Funktionen, eine nach der anderen

Ansichten

Stell Chats nebeneinander, gib einem die ganze Bühne oder reih sie auf. Ein Klick sortiert jede Karte nach Art oder macht aus der Fläche ein Board mit dem, was läuft, und dem, was fertig ist.

Heute

Eine Karte, die zeigt, wie lange du heute gearbeitet hast, in 15-Minuten-Blöcken, getrennt nach Claude und Codex. Sie vergleicht heute mit der letzten Woche und zeigt Tokens, Nachrichten und was jede Nachricht kostet.

Übernahme

Wenn Claude Code mitten in einer Aufgabe das Kontingent ausgeht, übernimmt Codex mit einem Klick. Es liest, was Claude schon gemacht hat, und macht mit derselben Aufgabe weiter.

Wettlauf

Gib Claude Code und Codex dieselbe Aufgabe. Jeder arbeitet in seiner eigenen Kopie deines Ordners, nebeneinander, und du behältst das Ergebnis, das dir gefällt. Dein echter Ordner bleibt unberührt, bis du dich entscheidest.

Warteschlange

Eine Aufgabenliste, die die KI selbst abarbeitet. Sie erledigt eine Aufgabe, prüft sie, behält sie und geht zur nächsten. Wenn etwas kaputtgeht, machst du diesen Schritt rückgängig.

Einbruch

KI-Agenten versuchen, in deinen eigenen Code einzubrechen, bevor es jemand anderes tut. Licht führt zuerst in Sekunden Hunderte schnelle Prüfungen aus, dann sucht Codex und Claude Code jeweils in ihrem eigenen Bereich. Ein vierter Agent schließt jede gefundene Lücke und beweist die Reparatur, dann greifen die anderen erneut an, bis jeder Weg hinein zu ist. Hier gezeigt an einem kleinen Beispielshop.
