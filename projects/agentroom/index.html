AgentRoom

01 / DESCRIPTION

What it is.

AgentRoom is an Electron desktop environment where AI coding tools appear inside a navigable three-dimensional room.

02 / EXPLANATION

What it does.

  1. Navigate a lamp-lit 3D room with two agent characters.
  2. Choose between Claude Code, Codex, and configured agent recipients.
  3. Use project-oriented conversations and workspace controls.

How it works.

Its Three.js scene includes two character agents at a shared desk. The chat controls let the user select Claude Code, Codex or another configured recipient; project context and voice interaction are explored in the desktop application.
