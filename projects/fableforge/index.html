01 / Overview

What is FableForge?

FableForge is a local-first agent workflow experiment organized around finishing work with evidence.

A local-first framework organized around goal contracts, memory routing, execution, review and repair.

02 / Inside the project

What it actually does.

  1. Convert raw requests into goal contracts.
  2. Route contextual memory and plan workflow stages.
  3. Execute, critique, verify, and retry with explicit evidence.

How it works

Its documented pipeline turns a user request into a clarified goal, pulls relevant context, plans execution steps, then applies critique, verification and repair. The goal is to make a workflow inspectable instead of silently declaring success.
