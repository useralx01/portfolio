01 / Overview

What is Personal Agent OS?

Personal Agent OS is a supervisor between incoming requests and an execution worker.

Supervisor for turning messages and Codex jobs into auditable, verified task executions.

02 / Inside the project

What it actually does.

  1. Parse Telegram and local API requests into contracts.
  2. Gate tool-worker output with machine-readable verification.
  3. Track durable jobs and audit outcomes.

How it works

A Telegram or local API message becomes a durable job with an explicit contract. The supervisor prepares personal context, routes work to Codex, and checks returned output against a machine-readable result envelope before recording its audit history.
