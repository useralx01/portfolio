01 / Overview

What is Clip Agent?

Clip Agent is a local workflow for turning an existing longer YouTube video into several vertical TikTok clips.

Automated YouTube-to-TikTok clip preparation workflow.

02 / Inside the project

What it actually does.

  1. Split queued long-form videos into short parts.
  2. Create vertical 1080x1920 output with blurred fill.
  3. Prepare labeled Part 1, Part 2, and Part 3 clips.

How it works

The scripted flow takes a queued video, selects defined time ranges, crops or fills the frame for 1080x1920 output, and labels the clips by part. The saved tool and its archive overlap an older YouTube-to-TikTok project folder.
