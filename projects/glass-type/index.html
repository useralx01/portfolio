01 / Overview

What is Glass Type?

Glass Type is a web component for live reflective metallic lettering.

Reusable live reflective text component for web and Electron interfaces.

02 / Inside the project

What it actually does.

  1. Render metallic/silky text in HTML.
  2. Animate letters without embedding a video.
  3. Reuse in websites and Electron shells.

How it works

Instead of exporting each title as a static image or video, the component renders and animates text in the page itself. The same component can be reused inside Electron-based UI through its web renderer.
