01 / DESCRIPTION

What it is.

3D Character is a collection of modeling and visual-comparison experiments.

02 / EXPLANATION

What it does.

  1. Model and refine character faces and body variations.
  2. Compare appearance renders across iterations.
  3. Produce Blender-oriented assets and validation images.

How it works.

Its files contain iterations of character appearance and scripts that prepare, align or compare renders. The work is primarily an asset-production workflow, not a standalone end-user application.

03 / DEMONSTRATION

See it in action.

Original comparison sheets and rendered character images are included.

Scope: Image sheets are real creative work outputs; not a standalone software application.
