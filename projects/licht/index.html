Canvas app

Licht

Licht is my own desktop app for working with several AIs at once. ChatGPT, Codex and Claude Code chats, notes and tools all sit as cards on one endless canvas, instead of being buried in browser tabs.

I built it because I usually have five or six AI chats going on the same project and kept losing track of which one was doing what. On a canvas I can see them all, move them around and group them by task.

Personal tool · in development

Why I built it

On a normal day I work with ChatGPT, Codex and Claude Code at the same time, often on the same project. In tabs and separate windows, I kept losing track of which chat was doing what and where a good answer was.

I wanted a workspace where I could see all of them at once, the way you'd spread papers out across a desk.

What it does

Licht is an endless canvas. Each chat, note or tool is a card you can move, resize and group. You can pan and zoom, use a mini-map to jump between areas, and switch layouts when you want to focus on one chat.

Codex and Claude Code run as real agents inside their cards, so you can watch them work step by step. ChatGPT chats use your own signed-in account, and two connected cards read each other's answers before they reply.

On top of that sit the features I use most: a Race between Claude Code and Codex on the same task, a Takeover when one runs out of usage, a Line up of tasks the AI works through alone, a Break in mode where agents attack my own code and fix what they find, and a Today card that shows where my hours and tokens went. Each one has its own short video below.

How it's built

Licht is an Electron app written in plain JavaScript. Codex and Claude Code run through their own command-line tools, and ChatGPT runs through its website inside the app.

It has its own look: a dark, glassy design built around the chrome star logo.

Where it stands

The canvas itself works well. The way it connects to each AI is the part I'm rebuilding now, so chats stay reliable and in sync instead of breaking when a website changes.

Right now it's a tool for my own work, not something other people can install yet. The tutorial above shows it as it is today.

Features, one by one

Views

Put chats side by side, give one the whole stage, or line them up in a row. One click sorts every card by kind, or turns the canvas into a board of what is working and what is done.

Today

A card that shows how long you worked today, in 15-minute blocks, split by Claude and Codex. It compares today with the last week and shows tokens, messages and what each message costs.

Takeover

When Claude Code runs out of usage in the middle of a job, Codex picks it up with one click. It reads what Claude already did and carries on with the same task.

Race

Give Claude Code and Codex the same task. Each works in its own copy of your folder, side by side, and you keep the result you like. Your real folder stays untouched until you choose.

Line up

A to-do list the AI works through by itself. It does one task, checks it, keeps it and moves to the next. If something breaks, you undo that step.

Break in

AI agents try to break into your own code before someone else does. Licht first runs hundreds of quick checks in seconds, then Codex and Claude Code each hunt in their own area. A fourth agent fixes every hole it finds and proves the fix, then the others attack again until every way in is closed. Shown here on a small sample shop.
