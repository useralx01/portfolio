01 / Overview

What is Telegram Trade Actor?

Telegram Trade Actor is an experimental local component for collecting Solana-related trade signals from Telegram messages.

Experimental Telegram signal collector with a separate local action layer.

02 / Inside the project

What it actually does.

  1. Poll Telegram Bot API for messages.
  2. Parse Solana contract addresses and trade-language signals.
  3. Persist messages and action records in SQLite.
  4. Keep separate from read-only wallet intelligence research.

How it works

It polls a configured Telegram bot, records message data and offsets, parses contract addresses and trade-language signals, and stores the resulting events in SQLite. A parsed message is not proof that an on-chain trade occurred.
