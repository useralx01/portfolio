01 / Overview

What is URACS?

The saved URACS v2 file is a dark mission-control dashboard for seeing several AI workers in one place. It presents agent cards, task activity and status summaries as a single interface.

An early agent dashboard presenting separate workers, task information and current activity in one interface.

02 / Inside the project

What it actually does.

  1. Four agent cards for Seraphim, Claude Code, Codex, and Antigravity.
  2. Mission-control layout with task counters and activity panels.
  3. Separate OpenClaw routing-plugin plan preserved alongside the dashboard.

How it works

The visible dashboard organizes Seraphim, Claude Code, Codex and Antigravity into separate panels, with an activity list beneath them. A separate document describes an OpenClaw routing plugin, but that plan should not be confused with verified working integration.
